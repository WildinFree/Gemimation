# Gemimation

Animated-Shorts-Gemini skill for portable animation creation.

Portable creative guidance and optional animation engines for turning a supplied script and audio into a vertical cartoon short.

Current package version: **1.1.0**.

Start with [START_HERE.md](START_HERE.md). Model instructions are in [SKILL.md](SKILL.md); browser engines and API guidance are in [code/README.md](code/README.md).

## Versions

- **1.0.0:** distilled creative guides, selected references and timing helper.
- **1.1.0:** preserved engine source, self-contained browser runtimes/demo and optional image/video QA.

The latest standalone ZIP is kept in [releases/](releases/). Earlier versions remain available through Git history. The source tree represents the current version. Keep this repository private because it includes private visual study references.

For updates, change VERSION, validate the affected code and guides, package a versioned ZIP and create a matching version tag. Keep prior source versions in Git history; retain only the latest ZIP in the current tree.

The original local skill is maintained separately and is not included here.
