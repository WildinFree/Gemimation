# Animated-Shorts-Gemini

A self-contained creative pack for turning your script and audio into a vertical cartoon short. No previous project or installation is needed. Optional self-contained browser engines preserve the original drawing, acting and scene logic.

Give the chat this package, your script and your audio, then use this prompt:

> Use SKILL.md and the included guides to create an animated short from my script and audio. Keep the words and voice unchanged. Make creative decisions yourself, follow the established visual language, and use the strongest production methods available in this chat. Carry the work through to a video if your tools support it. Read references/README.md before using the study images.

If the chat cannot open the ZIP, extract it and attach SKILL.md and the six guide documents as ordinary files. Add the selected reference sheets when useful. Give the model code/README.md and code/API.md if it can work with executable browser output; supply the relevant runtime or the self-contained demo as needed. Source modules and Python tools are optional. Do not load every source file just to use the pack.

- **SKILL.md** gives the model its task and decision rules.
- **guides/** holds the complete creative guidance, grouped by production decision.
- **references/** contains five camera/composition studies and instructions for reading them.
- **examples/** shows a worked beat and a timing-plan format.
- **tools/** contains timing helpers and optional image/video review scripts.
- **code/** contains ready-to-use browser engines, editable source, API guidance and library notices.
- **examples/browser-demo.html** is a single-file executable engine prototype with no network requests.

Read the written visual rules before the images. The study characters and captions are not the target style.
